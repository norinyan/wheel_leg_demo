## 问题与解决方法

| 问题 | 解决方法 / 结论 |
|---|---|
| RViz启动D-Bus崩溃 | 专用AppArmor放行必要无障碍D-Bus通信，策略已持久保存；原版RViz启动通过 |
| Conda与ROS库路径混用 | ROS终端显式使用系统PATH并source ROS环境；不手动覆盖LD_LIBRARY_PATH |
| Gazebo端口被占用 | 在旧仿真启动终端Ctrl+C退出；关闭GUI不等于结束gzserver |
| ROS发现其他电脑的节点 | 每个终端域76＋LOCALHOST_ONLY=1；已运行的旧节点需重启 |
| 上楼曾停在第二阶 | 当时仿真时钟受额外模型资源加载阻塞；移出额外模型，修正批量位姿更新与状态提示，完整上楼复验通过 |
| 低清视频与规划线缺失 | 同一仿真记录离线生成双视角，补齐全局/局部线和落足点；统一时间轴合成30fps视频，完整解码通过 |
| 过程产物和过期说明堆积 | 先完整备份，再清理；正式数据与临时产物分开，每次阶段验收后整理，更新当前说明而非重复追加历史 |
